Como manter este dashboard sempre atualizado

Este arquivo HTML é autossuficiente: o código não precisa ser refeito a cada atualização. Há duas formas de atualizar os dados:
  1. Selecionar arquivo (sempre funciona): clique em "ou selecionar arquivo" e escolha o Cronograma_-_britagem_03.xlsx mais recente. Tudo é recalculado no seu navegador, nenhum dado é enviado a servidor.
  2. Link fixo (mais prático, mas depende do servidor de hospedagem): cole no campo "Link fixo" a URL direta de download do arquivo e clique em "Carregar do link". Para carregar automaticamente sempre que a página abre, edite a constante DATA_SOURCE_URL no início do <script> deste HTML.
Atenção ao link fixo: só funciona se o servidor permitir acesso "CORS" sem login (links comuns de SharePoint/OneDrive corporativo costumam bloquear). Se falhar, use a opção de selecionar arquivo.

As curvas agora usam diretamente as colunas Data início planejado / Data de conclusão planejada e Data real de início / Data real de conclusão da aba "Cronograma priorizado" — não há mais um modelo simulado, é o cronograma real item a item.
